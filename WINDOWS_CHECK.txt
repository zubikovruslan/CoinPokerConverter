Проверка первой Windows-сборки

1. Распаковать архив целиком. Запустить CoinPokerConverter.exe обычным двойным щелчком.
   Ожидается русское окно с тремя вкладками. Не требуется установленный Python.
2. Ввести свой ник и проверить таблицу Splash: NL2/5 всем0%; NL10/25/50 всем60%.
3. Добавить исходную историю CoinPoker, выбрать полную выгрузку и нажать конвертацию.
   Ожидается ZIP с папками Import и Excluded, README и таблицами отчёта.
4. Открыть README внутри результата. В отдельной базе H2N3 импортировать два TXT из Import.
   Сравнить число рук и результат Hero с README. Выбрать игрока в руме PS.
5. Повторить тот же вход с тем же ником в режиме «Только новые руки».
   Ожидается 0 новых принятых рук. Исключения останутся доступными для повторной проверки.
6. Перезапустить приложение. Проверить сохранение профиля и истории.

Если окно не открылось: сообщить версию Windows и текст ошибки либо содержимое
%LOCALAPPDATA%\CoinPokerConverter\startup-error.txt, если этот файл создан.
Если цифры импорта отличаются: нужны Summary.json / README результата и снимок отчёта H2N3.
Общая доля Splash не входит в итог H2N3; корректный EV Splash этим тестом не доказывается.

Статус на момент выпуска: нативный Windows-запуск ещё не проверен.
