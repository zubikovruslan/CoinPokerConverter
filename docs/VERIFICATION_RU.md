# Проверка 0.1.0-beta.1

Подтверждено фактическими запусками:

- 28 автоматических проверок, включая 11 независимых отрицательных сценариев.
- На контрольной базе: 32 186 обычных рук / +203,99 и 187 Splash / +32,34; 47 исключений.
- Каждый принятый ID и текст совпадает с прежними контрольными файлами.
- Повторный режим «только новые»: 0 выгружено, 32 373 пропущено; исключения доступны снова.
- Отмена и ошибка создания ZIP не расходуют историю. Ошибка записи истории после
  сохранения ZIP возвращает путь к готовому результату и предупреждение.
- GUI: запуск, полный/новый режим, сохранение профиля, пути с кириллицей;
  видимость кнопок при 1000×800 и 860×690. Проверка выполнялась в Linux с Tk8.6.
- Windows launcher скомпилирован как PE AMD64 GUI; среда CPython включена в пакет.
- Контроль целостности ZIP и соответствие файлов манифесту.

Не подтверждено:

- Нативный запуск этого exe на Windows 10/11, перетаскивание файлов и системные диалоги Windows.
- Импорт в H2N3 из пользовательского запуска программы. Текст конвертации совпадает
  с ранее проверенными файлами; это не заменяет проверку программы на целевой ОС.
- Полный EV, исходный внешний банк и общие выплаты Splash в H2N3.

В пользовательский пакет не включены реальные истории, персональный ник, SQLite
и история разработчика. Синтетические тесты находятся только в архиве исходного кода.

Статус: первая тестовая сборка; следующий шаг — `WINDOWS_CHECK.txt` на Windows x64.
